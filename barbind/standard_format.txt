
something like:
@|~_left_:~-action-|
gets axiom bound to:
@|#_s_:#-leftalt-|

gets finally bound to:
@|o:alt|

then gets program-specific bound to things like:
- A-o
- Alt+o

something like:
@|#_j_:#-shift-|

gets functioned to:
$|!_j_|

then mapped to:
J


capture chars can and should probably be dynamic.

cases:
- multiple mods:
    @<~(left):alt&#[meta]>
    ~ use '&'
