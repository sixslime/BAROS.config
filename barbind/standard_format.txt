
something like:
@<~(left):~[action]>

gets axiom bound to:
@<#(s):#[leftalt]>

gets finally bound to:
@<o:alt>

then gets program-specific bound to things like:
- A-o
- Alt+o

something like:
@<#(j):#[shift]>

gets functioned to:
@<!(j)>

then mapped to:
J


capture chars can and should probably be dynamic.

cases:
- multiple mods:
    @<~(left):alt&#[meta]>
    ~ use '&'
